ВентУчёт

Фактическое обследование систем вентиляции · расширенный список систем · без проектных объёмов
Полнофункциональная автономная версия. Перечень систем перенесён из предварительной сводной таблицы, требует сверки с оригиналом спецификации. Данные хранятся на этом устройстве (IndexedDB). Облако и вход по паролю пока не подключены. Для защиты результатов обхода ежедневно сохраняйте резервную копию. Не очищайте данные браузера.

Внести данные по месту

Если системы нет в списке, нажмите «＋ Добавить систему». Она сохранится и появится в ведомостях.

Размер можно выбрать из списка или ввести вручную. Новый размер запомнится после сохранения записи.

Каждая фасонка — отдельная запись. Площадь можно внести позже.

Как вводить

При первом обходе укажите фактически смонтированное и оставшееся по участку. Если остатка нет, оставьте поле «Осталось» пустым — программа сохранит 0. Позже откройте запись и нажмите «Закрыть часть остатка» — объём перенесётся в монтаж. Этаж, система и оси сохраняются после добавления следующей позиции.

Фактическая ведомость

Расчёт изоляции: площадь изолированных изделий × 1,10. Запас 10% отдельно от факта. Площадь воздуховода считается по наружному геометрическому периметру без поправки на толщину изоляции. Для фасонок площадь вводится вручную.

Детализация по позициям

Красным выделены отсутствующие фасонные изделия. Для изменения отдельной позиции используйте вкладку «Записи».

Выгрузка

CSV-файлы открываются в Excel. Журнал сохраняет каждую отдельную позицию с осями, примечаниями и состоянием изоляции.

Резервная копия — обязательно после обхода

Восстановление заменяет все записи на этом устройстве. Сначала сохраните текущую копию.
