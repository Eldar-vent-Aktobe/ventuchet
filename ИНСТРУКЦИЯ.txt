ВентУчёт — локальная PWA для Android и Windows.

Быстрая проверка: откройте index.html в Chrome. Внимание: открытие через файловый менеджер (file://) может не поддерживать IndexedDB. Не вводите реальные данные, пока не проверили сохранение после перезапуска.

Для постоянной работы и установки на экран телефона: разместите ВСЕ файлы папки на одном HTTPS-адресе. Откройте адрес в Chrome Android, меню ⋮ → Добавить на главный экран / Установить приложение. После первой загрузки приложение может работать без сети.

Данные хранятся в браузере на конкретном устройстве и конкретном адресе сайта, не синхронизируются автоматически. При смене адреса или устройства перенесите данные через Экспорт → Резервная копия JSON → Восстановить.

Перед использованием сделайте тест: добавить систему и размер, сохранить запись, закрыть приложение, открыть и проверить; выгрузить резервную копию, убедиться что файл скачан. После каждого обхода скачивать JSON и хранить копию отдельно от телефона.

Excel: раздел Экспорт → Журнал CSV / Сводка CSV. К1–К10 не включаются автоматически. Список систем предварительный; недостающие можно добавить вручную.

Приложение не имеет облачной авторизации, серверного хранилища и APK. Не является приложением из Google Play.
